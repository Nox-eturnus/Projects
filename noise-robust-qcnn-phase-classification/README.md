# Noise-Robust Quantum Convolutional Neural Network for Quantum Phase and State Classification

Research-oriented testbed for quantum-native QCNN classification of many-body ground states, architecture benchmarking, noise-aware training, classical and variational quantum baselines, transition-region generalization, device-derived noise transfer, and IBM Quantum hardware validation.

This repository does **not** claim quantum advantage. Classical baselines are tagged by the information they receive so that full-state, tomography-like, and direct quantum-state access are not silently compared as if they were identical resources.

Follow the implementation handbook phase by phase. A phase is complete only when its run command and validation gate pass.
