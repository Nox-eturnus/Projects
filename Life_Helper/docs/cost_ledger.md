Tracks Decision 11 (zero recurring cost) against measured reality. Every
phase that touches one of these components records its measurement here.
Any row above 50% of its free allowance is a design problem to fix before
it becomes a billing problem — see Part I2.

## Notes

- The GitHub Actions workflow (`.github/workflows/life-helper-verify.yml`)
  is scoped to `Life_Helper/**` via a `paths` filter so unrelated changes
  elsewhere in this monorepo don't burn Actions minutes.
- The Google Cloud blocker is the first real deviation from Decision 11's
  "no card on file anywhere" rule. It's scoped narrowly (Calendar only) and
  the plan itself (Decision 12) anticipated exactly this failure mode, so
  it's a recorded, accepted deferral — not a silent gap.
- Rows that still say "not yet" or "not built" are expected at this point —
  they belong to phases that haven't started. Populate them as each phase
  builds the component and measures it against its dashboard.
