# End-to-End Quantum-Secure Network Testbed with Adaptive QKD, Finite-Key Security & Standards-Compliant Key Management

Research-oriented software testbed for practical decoy-state BB84, MDI-QKD, finite-size key analysis, classical post-processing, key management, multi-node routing, and adaptive protocol/parameter selection.

This repository is a **software/emulation research testbed**. It does not claim that ordinary laptop network traffic has been physically protected by a deployed quantum channel.

Implementation instructions are kept in the project handbook. Run phases in order and do not mark a phase complete until its validation gate passes.
